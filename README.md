# 🏦 Smart-Lender: AI-Powered Loan Approval Prediction System

## 📌 Project Overview

Smart-Lender is a Machine Learning-based web application that predicts whether a loan application is likely to be approved or rejected based on the applicant's financial and personal details.

The project uses historical loan data to train a predictive model and provides real-time predictions through a user-friendly Flask web interface.

- Loan Approval Prediction
- Interactive Flask Web Application
